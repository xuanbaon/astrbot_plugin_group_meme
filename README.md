# AstrBot 群发表情（group_meme）

> 让她把表情包发到指定的群 —— 只给群号和心情，剩下的不用你管。

## 它解决什么问题

想让 bot 往**另一个群**发东西，多数人会撞上这个报错：

```
error: invalid session: aiocqhttp:group:123456789
```

原因不神秘：跨会话发送要一个 `平台ID:GroupMessage:群号` 的字符串，而大家（包括大模型）
会本能地写成 `平台类型:group:群号`。
`aiocqhttp` 是平台**类型**，不是平台 **ID**；`group` 也不是合法的 `GroupMessage`。
只要拼错一个字符，消息就直接投递失败 —— 而且常常是「静默失败」，你只看到 bot 不说话。

这个插件把整套拼接包在自己身上：

- 会话字符串由插件生成，模型/用户只需要说**群号或群名**
- 图库自动发现，不用改代码去适配某个具体的表情插件
- 除了命令，还支持一句话直发（不经过大模型）

## 命令

| 命令 | 作用 |
| --- | --- |
| `/群发表情 123456789 开心` | 发一张「开心」的表情包到该群 |
| `/群发表情 示例群名 委屈` | 群名片段也行 |
| `/群列表` | 列出所有群，以及**正确的会话写法** |

命令仅管理员可用（`PermissionType.ADMIN`）。

`/群列表` 是排错时最有用的东西，它会把每个群的
`<平台ID>:GroupMessage:123456789` 原样打出来，照着抄就不会再错。

## 一句话直发（不需要大模型）

管理员在群里说「**发张表情包**」，或在私聊说「**去群里发张 123456789 委屈的**」，
插件用规则直接识别并发送，**不经过大模型**——所以模型限流、超时、
Provider 挂掉的时候，这条路依然能用。

识别规则：同时出现「表情 / 梗图」「群」「发 / 来 / 甩 / 丢 / 整」才会触发；
「别发」「不要发」和带「吗 / ？ / 能不能」的提问会被排除，聊天时不会误触发。

触发条件满足时插件会唤醒，不满足时连唤醒都不会发生 —— 群里不 @ 她也能用，
平时也不会插嘴。另外，如果这一次请求已经由一句话通路发出去了，
模型随后再调用 `send_meme_to_group` 会被告知「已经发过了」，不会重复发两张。

## 图库从哪来

默认**自动发现**，不写死任何插件名。扫一遍 `data/plugin_data`：

| 目录长相 | 当成 |
| --- | --- |
| 有 `catalog.json`（里面有 `items`，带 `tags` / `emotions` / `intents`） | 带标签的图库，按标签选图 |
| 有 `packs/` 子目录 | 表情包集合，按子目录名当标签 |

两处都有就都收，按文件路径去重。也可以手动加：

```yaml
auto_discover: true
libraries:
  - "my_pack"                       # 相对 data/plugin_data
  - "D:/memes/日常"                 # 绝对路径
```

指向普通目录时，目录里的图片全会收，子目录名当标签用。

选图逻辑：把要说的心情（如「无语」）展开成同义词，给每张图的标签算分，
最近在这个群发过的扣分，避免连续刷同一张。

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `natural_trigger` | `true` | 是否允许一句话直发 |
| `cooldown_seconds` | `5` | 同一群的发送冷却，防刷屏 |
| `auto_discover` | `true` | 自动扫 `plugin_data` 找图库 |
| `libraries` | `[]` | 额外图库目录 |

## 安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/xuanbaon/astrbot_plugin_group_meme.git
# 重启 AstrBot，或在 WebUI 插件页重载
```

装好后先发 `/群列表` 确认能读到群，再发 `/群发表情 <群号> 开心`。
没图可发时会明确告诉你「图库里没有匹配的表情包」，而不是沉默。

## 兼容性

- AstrBot `>= 4.17.0`
- 发送走 `context.send_message(umo, chain)`，与平台无关；
  群列表依赖 OneBot 实现的 `get_group_list` 动作（aiocqhttp / NapCat / SnowLuma 等）
- 无第三方依赖
